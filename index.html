    Guide: what each Excel cell does

    How the page works

    1. Type the plate-reader numbers (OD) into Plate readings. Type the blank wells into Blank readings.
    2. The page subtracts the blank from each reading.
    3. It finds the control average. This is the 100% reference.
    4. It turns every well into a viability % of that reference.
    5. For each group it shows the mean, SD, %RSD, N and SEM. It draws the chart.

    What is different from your Excel sheet

    • SD, %RSD, SEM: the page uses each group's own wells. In Excel, column D reads the wrong blocks (for example D25 reads the 1 nM wells, D30 reads the control, D31 and D32 reach into empty rows). The formula was copied down and its range moved.
    • 100% reference: Excel divides by a typed number in D18. The page uses the control average by default. You can still choose a fixed value.
    • Empty wells are skipped, so N shows how many wells have numbers. In Excel an empty well counts as 0.
    • Chart: concentration is a real number on the X axis. In Excel the concentrations are stored as text, so the chart used positions 1 to 8. A log scale is available.
    • Mean OD ("Conct Avr") is calculated for every group, including the control. In the Car sheet the Excel column runs from 60 nM down to 0.1 nM, while the concentrations run up from 0, so the values sat next to the wrong concentration.
    • Summary order: lowest concentration first.
    • Units: the Excel header says "Conc(uL)". The page uses a unit you can edit (nM).
